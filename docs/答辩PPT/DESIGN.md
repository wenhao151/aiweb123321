## 全局视觉约定

### ① 画布与安全区
- 画布 1280×720；页面 padding：上下 60px / 左右 60px（硬下限）
- 顶条为全宽母版（0–68px），内容区从 y=68 起，左右仍守 60px；页脚固定 y=670，左右 60 / 1220
- 封面页与封底页不套用顶条与页脚

### ② 配色（学术宝蓝 + 白底）
| 槽位 | Hex | 用途 |
|---|---|---|
| 主色 | `#1E4FA8` | 顶条、编号块、章节号、强调 |
| 辅色 | `#3D7BD9` / `#E8EFF8` | 描边、卡底、信息横幅底 |
| 强调色 | `#D9534F` | 关键风险 / 关键结论，≤3% |
| 正文色 | `#1A2230` / `#4A5568` / `#8B97A8` | 主 / 副 / 辅助文字 |
| 底色 | `#FFFFFF` | 主背景 ≥60% |
| 分隔线 | `#D6DCE5` | 1px 卡片描边、表格线 |

### ③ 字体系统
- 中文：`Source Han Sans SC` / `Microsoft YaHei`（思源黑体系，全篇不混宋体）
- 西文与数字：`Arial`
- 字号阶梯：封面主标 60 / 副标 28 / 页主标（顶条白字）34 / 卡内小标 24 / 正文 20 / KPI 巨数字 72 / 注释与页脚 14
- 同页文字样式组合 ≤4 种；正文 ≥20px，卡内小标 ≥22px，任意可见文本 ≥14px

### ④ 视觉母题
- 全篇统一「顶部深蓝标题条（68px）+ 标题下 1px 贯通细线 + 固定位置页脚页码」
- 编号块统一用 `01 / 02 / 03` 深蓝底白字方块，不混用其他编号形式

### ⑤ 配图清单
| 文件 | 等级 | 生成方式 | 真实内容 | 使用页 |
|---|---|---|---|---|
| 无外部位图 | L1 | Box / SVG 手绘 | 分层架构图、四级引导流程链、受约束润色流程 | P4 / P6 / P7 |
| 顶条编号块 | L3 | Box | 全篇固定位置 | 所有内容页 |

> 不使用生成式配图：技术答辩以结构图与真实数据为主，避免装饰性图片。

## 逐页 description（本页实际讲什么）

1. 作品名、一句话定位、赛道、学校、三位队员与指导老师、时间。
2. 三个痛点（学习过程被替代 / 幻觉无法核对 / 脱离课程实际）与一句话定位「拒绝给答案、只给可溯源提示」。
3. 四个模块（知识库 / 分层教学 / 截图报错 / 演示模式与一键复现）与四条底线（有据可查、无据则明说、引导优先、演示模式诚实）。
4. 浏览器层、FastAPI 接口层、应用层（检索 / 教学 / 报错）、支撑层；说明 `TeachingRequest.retrieval` 由调用方显式传入，检索通道可替换可单测。
5. 五项选型：自建链路（约 200 行）、512 维离线哈希向量、Chroma 持久化、0.75 余弦 + 0.25 字面覆盖率、OpenAI 兼容协议；主动说明哈希向量是词面相似度而非语义向量。
6. L1 知识点提示 → L2 解题思路 → L3 局部示例 → L4 相似例题；服务端 `current_level + 1` 钳制、引导模式须先提交尝试。
7. 受约束润色流程（问题 + 分类 + 层级 + 可信片段 + 讲解块 → 模型 → 引用校验与护栏）；实测 `demo_mode:false`、`llm_status:"model"`、4.86 秒；失败自动回退模板。
8. 六道护栏：引用来自本次命中集合、代码块截断与骨架化、不执行用户代码、密钥只放后端、DOMPurify、OCR 不确定性标注。
9. 问知识库外问题 → 明确「资料不足」不伪造引用；点开引用卡片 → 核对文档名、页码与相关度。
10. 124 passed、check_demo 6/6、npm run build 通过；5 步复现命令，强调 `seed_demo.py` 必做因为 `storage/` 不入库。
11. 四项技术创新（检索驱动四级引导 / 输出侧泄露护栏 / 离线可复现轻量 RAG / 可解释诚实设计）与两项应用创新。
12. 逐条列出当前局限与对应规划，明确「规划项均不在当前代码中」。
13. 致谢、作品名、Public 仓库地址与团队署名。
