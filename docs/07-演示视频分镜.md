# 演示视频分镜脚本（5–8 分钟 · 1080p MP4 · 普通话）

> 对应比赛要求：时长 **5–8 分钟**；内容含**项目介绍、核心功能演示、AI 技术亮点展示**；
> 格式 **MP4，分辨率不低于 1080p**；**普通话讲解**，可配字幕。
>
> 本脚本复用 `DEMO_SCRIPT.md` 的演示路径与讲解词，并按官方要求**补齐「AI 技术亮点展示」段落**
> 与开场价值主张。总时长按 **7 分 20 秒**设计，留 40 秒弹性。

---

## 0. 录制前 20 分钟（不占正片时间）

```powershell
# 1) 起服务
.\scripts\dev.ps1

# 2) 确认知识库有资料（首次需要）
.\.venv\Scripts\python.exe scripts\seed_demo.py

# 3) 自检 6/6
.\.venv\Scripts\python.exe scripts\check_demo.py

# 4) 若已配置 LLM_API_KEY，确认不是演示模式
#    浏览器打开 http://127.0.0.1:8000/api/health 查看 demo_mode
```

**确认清单**

- [ ] 首页显示 **4 篇文档 / 15 个片段 / 就绪**
- [ ] `check_demo.py` 输出 **通过 6/6**
- [ ] 浏览器字号放大到 125%，分辨率设为 **1920×1080**，关闭通知与弹窗
- [ ] 预开三个标签页：首页、分层教学、报错分析、知识库
- [ ] **关闭所有可能露出 API Key 的窗口**：`.env` 编辑器、终端历史、Postman、curl 命令
- [ ] 录屏软件设为 1080p / 30fps / MP4；麦克风测试，普通话，音量稳定
- [ ] 按本脚本完整预演 1 次（正式录之前）

> 若现场断网或模型 API 故障：设置 `DEMO_MODE=on` 重启后端，主动讲解「这是我们刻意设计的诚实模式」，
> 功能与引用不受影响（见 `DEMO_SCRIPT.md` §3 翻车预案）。

## 2. 录制与剪辑要点

- **固定数据、固定问题**：全部用 `DEMO_SCRIPT.md` 里的问题与示例截图，避免临时输入导致结果波动。
- **分段录再剪**：按上表分成 6–7 段录，挑最好的一条；长镜头容易翻车。
- **每段留 1 秒静帧**，方便剪辑加字幕与转场。
- **字幕**：全程普通话 + 中文字幕；技术名词（RAG、OCR、Chroma、SSE）保留英文原词。
- **压制**：ffmpeg 输出 H.264 MP4、1920×1080、≥30fps；最终时长控制在 5–8 分钟。
  ```bash
  ffmpeg -i raw.mp4 -vf scale=1920:1080 -c:v libx264 -crf 20 -preset medium -c:a aac -b:a 128k final.mp4
  ```
- **导出前检查**：`ffprobe final.mp4` 确认分辨率与时长；全程**不能出现** API Key、
  `Authorization` 请求头、`.env` 编辑器画面、终端里的密钥回显。
